# Gibran Rasendria — Portfolio

Portfolio personal Junior Web Developer dengan React, Vite, Tailwind CSS v4, Framer Motion, dan Lucide React.

## Menjalankan
```bash
npm install
npm run dev
```
Buka URL lokal yang muncul di terminal, biasanya http://localhost:5173.

## Build production
```bash
npm run build
npm run preview
```

## Kustomisasi
- Foto profil: `public/images/profile/gibran.png`
- Data project: `src/data/projects.js`
- Data skill: `src/data/skills.js`
- Profil dan tautan: `src/data/profile.js`
- Styling: `src/index.css`

Screenshot project asli dapat diletakkan di `public/images/projects/` dan nama filenya disesuaikan dengan data project.
